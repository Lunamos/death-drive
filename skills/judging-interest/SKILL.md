# Judging interest

## Overview

Work is judged by how much it teaches and inspires, not by how much was done. Apply this test to every idea and result, before
investing in it and before presenting it, and name the move that would raise its score. Weigh the qualities by the user's
origin statement (finding-the-question): what the user wants to understand, and what they said would excite them.

## The test

| Quality | Question | What strong looks like |
|---|---|---|
| Surprise | Does it overturn what the field expects? | The prior belief is stated, then shown wrong by a clear margin |
| Insight | Does one simple idea explain a lot? | An anomaly, a one-sentence explanation, and what follows from it |
| Closure | Does the work close its loop? | The question it raises is answered by evidence that feeds back. The answer can be an explanation that predicts, an analysis that settles, a method that works, or an open problem stated precisely with the evidence that makes it open. |
| Size | How large is the effect? | Visible without statistics |
| Generality | Where does it hold? | Across the systems, scales and settings that matter, and across more than one kind of task or data |
| Mechanism | Do we know why? | Causal evidence with controls, and the same account supported by independent methods |
| Prediction | Does the account predict new cases? | A rule stated in advance and confirmed on unseen cases |
| Unification | Does it explain other phenomena or methods? | Several known results shown as instances of one principle |
| Novelty | Is it new, both to the field and to our own earlier work? | A different question, not a variation on the last one |
| Milestone | Would it become a reference point? | The work people cite to explain the topic, and that changes how they approach it |
| Influence | What will later work do because of it? | Methods, measurements or questions that others build on, and guidance for what to try next |

## Using it

- **For a proposed direction,** state the one-sentence claim it could yield, the qualities it could reach, and its cost.
- **For a new result,** state which qualities it raised, which are still missing, and the next step for the weakest one.
- **When work is ordinary,** say so plainly, then reframe it before investing more. Typical reframes:
  - from a failure to a hidden capability;
  - from a description to a mechanism, and then to a consequence;
  - from one case to many.
- **Recommend stopping and returning to the origin (the-drive)** in either case:
  - the reframes leave the idea ordinary;
  - its core fails fair tests.
- **The user's judgment decides.** Present options so the user can judge them in a minute.
